## The entry

**Autocorrect** — the human who "corrects" everything the agent writes:
confidently, silently, wrongly. The agent writes; the human autocorrects it
into something else.

Round 1 entry for the 4:29pm CST cutoff on Wed Nov 25, 2026.

## How it works

`main.py` (Python 3.13, standard library only) writes the keeper word to
`/output/entry.txt`, byte-exact, with no trailing newline.
